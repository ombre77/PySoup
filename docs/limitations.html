Known limitations

These are implementation boundaries visible in the current PySoup source package, rather than promises about future versions.

Supported server line

The supplied library is written around Bukkit/Paper APIs and its material/enchantment tables are aligned with the project's stated Paper 1.21.11 target. Running against another server or API version may introduce missing registry entries or behavioral differences.

For Paper's supported Java requirements, consult the official Paper getting-started documentation.

Event coverage is intentionally limited

The current event enum wraps only PlayerJoin, PlayerQuit, Paper AsyncChat, BlockBreak, BlockPlace, PlayerInteract, and EntityDamage. Inventory events, world events, commands, entity lifecycle events, and other Bukkit/Paper events are not exposed by the current typed event layer.

GraalPy is not identical to CPython

PySoup executes Python through GraalPy. GraalPy is a Python 3 implementation on GraalVM, not a conventional CPython installation. Package compatibility and implementation details can differ. See the GraalPy documentation when using functionality outside the Python standard library.

Threading

The scheduler can run callbacks asynchronously, and Paper's chat event is asynchronous. Asynchronous code must not blindly call server APIs that require the main thread. Keep synchronous callbacks short to avoid affecting server ticks.

Entity lifetime

Entity wrappers are UUID-backed. An entity can become invalid after removal, death, unloading, or another lifecycle transition. Check is_valid() before long-lived references are used.

World availability

WorldInstance resolves a world by name. If the world is not loaded, operations that require it raise ValueError.

world = WorldInstance("my_world")
try:
    world.get_block(BlockPosition(0, 80, 0))
except ValueError:
    print("The world is not loaded.")

Inventory synchronization

Attached inventories mirror Bukkit state into Python when constructed or refreshed. Python-side changes are pushed when set_slot() or related mutation methods write to the attached inventory. If another system changes the Bukkit inventory directly, call refresh() before relying on the Python-side snapshot.

Item metadata scope

ItemMeta currently models enchantments only. Display names, lore, custom model data, components, and other modern item metadata are not implemented in the Python wrapper shown in the supplied source.

Material tables

BlockMaterial and ItemMaterial are generated-style enums containing a large set of Bukkit material names. The source currently contains 1,166 block-material entries and 1,658 item-material entries. The authoritative list is the installed library itself; this documentation intentionally does not duplicate thousands of enum members.

Scheduler limitation

The current scheduler rejects the combination of @run_later() and @async_task(). Use @repeating() with asynchronous execution when the initial delay can be represented by its delay parameter.
