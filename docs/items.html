Items & Inventory

The current item API is intentionally small: ItemStack carries material, amount, and ItemMeta; inventory wrappers manage slots and synchronization.

ItemMeta, ItemStack and Inventory will contain more fields in future updates

ItemStack

The current class is a dataclass with three fields:

FieldTypeDefault
materialItemMaterialrequired
amountint1
metaItemMetaempty metadata
 
from pysoup import *

diamond = ItemStack(ItemMaterial.DIAMOND)
stack = ItemStack(ItemMaterial.COOKED_BEEF, 16)

print(stack.material)
print(stack.amount)
print(stack.meta)

ItemStack.to_bukkit() converts the wrapper into a Bukkit ItemStack. ItemStack.from_bukkit(value) converts a Bukkit stack back and returns None when the input is None.

Item metadata and enchantments

ItemMeta currently stores enchantments as dict[Enchantment, int]. Its public conversion methods are apply_to_bukkit() and from_bukkit().

meta = ItemMeta({
    Enchantment.SHARPNESS: 5,
    Enchantment.UNBREAKING: 3,
})
sword = ItemStack(ItemMaterial.DIAMOND_SWORD, 1, meta)

When converting to Bukkit, PySoup applies each stored enchantment with Bukkit's addEnchant(..., level, True) behavior.

Enchantment reference

The current Enchantment enum includes the enchantments defined by the library, including PROTECTION, SHARPNESS, EFFICIENCY, MENDING, DENSITY, BREACH, WIND_BURST, and LUNGE.

Use to_bukkit() when you need the underlying Bukkit object. The wrapper also exposes metadata and compatibility helpers:

e = Enchantment.SHARPNESS

print(e.get_max_level())
print(e.get_start_level())
print(e.is_treasure())
print(e.is_cursed())
print(e.is_tradeable())
print(e.is_discoverable())
print(e.get_anvil_cost())
print(e.get_weight())
print(e.description())
print(e.display_name(5))

if e.conflicts_with(Enchantment.SMITE):
    print("These enchantments conflict")

Additional methods are get_min_modified_cost(level), get_max_modified_cost(level), can_enchant_item(item), get_active_slot_groups(), and get_exclusive_with().

Stack limits

Use the library functions rather than assuming every item stacks to 64.

limit = get_max_stack_size(ItemMaterial.ENDER_PEARL)
print(limit)  # 16

print(stackable_to(ItemMaterial.DIAMOND, 64))  # True
print(stackable_to(ItemMaterial.DIAMOND, 65))  # False

The library currently defines three stack-size categories: 1, 16, and 64. The 16-stack group includes snowballs, eggs, ender pearls, buckets, signs, hanging signs, and honey bottles. A broad set of tools, armor, filled buckets, potions, books, boats, minecarts, shulker boxes, mob armor, and other unstackable items are limited to one.

Inventory

Inventory(size, slot_filters=None, bukkit_inventory=None) can represent a detached inventory or wrap a live Bukkit inventory.

MethodPurpose
get_slot(index)Return the stack or None.
set_slot(index, item)Replace a slot and push the change to Bukkit when attached.
can_place(index, item)Check the configured slot filter.
add_item(item)Add as much as possible; return the remaining stack or None.
remove_item(index, amount)Remove up to the requested amount and return what was removed.
find_first(material, meta=None)Return the first matching slot index or None.
is_full()Return whether every slot is filled to its material's maximum stack size.
refresh()Re-read the attached Bukkit inventory.
to_bukkit(...)Populate or create a Bukkit inventory.

Adding and removing

inv = Inventory(9)

leftover = inv.add_item(ItemStack(ItemMaterial.DIAMOND, 70))
if leftover is not None:
    print("Could not fit:", leftover.amount)

removed = inv.remove_item(0, 4)
if removed is not None:
    print("Removed:", removed.amount)

PlayerInventory

PlayerInventory is a 41-slot inventory wrapper. Its helpers cover the held item, hotbar, armor, and offhand.

inventory = event.player.get_inventory()

held = inventory.get_held_item()
inventory.set_offhand(ItemStack(ItemMaterial.TORCH, 1))

helmet = inventory.get_helmet()
boots = inventory.get_boots()

hotbar = inventory.get_hotbar()
armor = inventory.get_armor_contents()

The wrapper uses the Bukkit layout: slots 0–8 are the hotbar, 9–35 main storage, 36–39 armor, and 40 offhand. Armor helpers map 36 to boots, 37 to leggings, 38 to chestplate, and 39 to helmet.

After modifying a player inventory wrapper, call player.push_inventory() to replace the live player's Bukkit inventory with the wrapper's current contents.

It is not necessary, but i recommand it in case of bugs and glitchs.

Slot filters

Inventory constructors accept a mapping such as {0: "fuel"}. The library currently registers the built-in filters "blank" and "fuel". Custom filter registration is available through the lower-level pysoup.inventory.slot_filter module.

Current API boundary. The source does not currently implement convenience methods such as ItemStack.add_enchantment(), set_name(), add_lore_line(), or has_item_meta(). Examples using those methods were removed from this documentation. Blame AI
