Your first script

Create a minimal PySoup script, reload it, and verify that the event bridge is working.

1. Create the scripts directory

After the plugin has started, use the scripts/ directory created by PySoup inside the plugin's data directory. Put your Python scripts there.

2. Create a join handler

Create scripts/welcome.py:

from pysoup import *

@on_event(Event.PlayerJoin)
def on_join(event: EventInfos.PlayerJoin):
    broadcast(f"Welcome to the server, {event.player.get_name()}!")

@on_event(Event.PlayerJoin) registers the function with the Paper event bridge. PySoup converts the raw Bukkit event into an EventInfos.PlayerJoin object, whose player field is a PlayerInstance.

3. Reload the scripts

Use the PySoup reload command provided by the plugin:

/pysoup reload

Reloading/Loading the first few times will take some time, but the speed increase each time you run the command

The exact console output is implementation-dependent, so do not rely on a particular wording or count. If the script fails to load, see Reading errors.

4. Test the script

Reconnect to the server. The join handler should broadcast a message containing the joining player's name.

Useful variations

from pysoup import *

@on_event(Event.PlayerQuit)
def on_quit(event: EventInfos.PlayerQuit):
    broadcast(f"Goodbye, {event.player.get_name()}!")

@on_event(Event.PlayerJoin)
def private_message(event: EventInfos.PlayerJoin):
    event.player.send_message("Welcome! This message is private.")

Important distinction: Python objects vs. live server objects

PlayerInstance, EntityInstance, BlockInstance, and WorldInstance are PySoup wrappers. Entity wrappers retain a UUID and resolve the live Bukkit entity when an operation is requested. A previously obtained entity can therefore become invalid after the entity is removed.
