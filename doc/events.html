Events

Register the Paper/Bukkit events currently wrapped by PySoup and work with typed event information.

Registering an event

from pysoup import *

@on_event(Event.PlayerJoin)
def on_join(event: EventInfos.PlayerJoin):
    event.player.send_message("Welcome!")

The decorator registers the function immediately when the script is evaluated. For wrapped events, the callback receives an EventInfos object. The current library wraps seven events.

Player events

@on_event(Event.PlayerJoin)
def on_join(event: EventInfos.PlayerJoin):
    print(event.player.get_name())

@on_event(Event.PlayerQuit)
def on_quit(event: EventInfos.PlayerQuit):
    broadcast(f"{event.player.get_name()} left the server")

Chat

PlayerChat wraps Paper's AsyncChatEvent. Its fields are player and message. The message is converted to a string by PySoup's component conversion helper.

@on_event(Event.PlayerChat)
def on_chat(event: EventInfos.PlayerChat):
    if "example" in event.message.lower():
        event.cancel()
        event.player.send_message("That message was blocked.")
Threading: Chat is an asynchronous Paper event. Keep the handler short and be careful with APIs that require execution on the server's main thread. See Scheduler for asynchronous work.

Block break and placement

@on_event(Event.BlockBreak)
def on_break(event: EventInfos.BlockBreak):
    event.player.send_message(
        f"You broke {event.block.block.name}"
    )

@on_event(Event.BlockPlace)
def on_place(event: EventInfos.BlockPlace):
    if event.block.block == BlockMaterial.DIAMOND_BLOCK:
        event.cancel()

Both payloads expose player and block. The block wrapper contains its material, integer block position, and world.

Player interaction

PlayerInteract contains player, an optional block, action, and an optional hand.

EnumValues
InteractActionLEFT_CLICK_AIR, LEFT_CLICK_BLOCK, RIGHT_CLICK_AIR, RIGHT_CLICK_BLOCK, PHYSICAL
InteractHandMAIN_HAND, OFF_HAND; None when no hand applies
 
@on_event(Event.PlayerInteract)
def on_interact(event: EventInfos.PlayerInteract):
    if event.is_right_click() and event.is_block_interact():
        event.player.send_message(
            f"Right-clicked {event.block.block.name}"
        )

The convenience predicates are is_left_click(), is_right_click(), is_block_interact(), is_air_interact(), and is_physical().

Entity damage

EntityDamage exposes entity, damage, and cause. The cause is provided as the Bukkit damage-cause name.

@on_event(Event.EntityDamage)
def on_damage(event: EventInfos.EntityDamage):
    if event.cause == "FALL":
        event.cancel()

Eventually, cause will be changed to an enum

Cancellation API

For cancellable event payloads, use cancel(), is_cancelled(), or set_cancelled(value).
