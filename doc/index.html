PySoup

Python scripting for Paper servers, with a small Python-facing API over Bukkit/Paper functionality.

What PySoup provides

PySoup runs Python scripts inside a Minecraft server through GraalPy and exposes a curated API for events, scheduling, entities, worlds, blocks, inventories, items, enchantments, and basic geometry.

Install the script, register an event, and reload it in-game.

Scheduler

Run immediate, delayed, repeating, and asynchronous tasks.

Requirements

The source package targets Paper 1.21.11 and Java 21. Paper's current documentation confirms Java 21 for the 1.20–1.21.11 line; newer Paper releases have different requirements. See the Paper getting-started guide before choosing a server version.

PySoup uses GraalPy rather than requiring a separate CPython installation. GraalPy is a Python 3 runtime designed to run Python code on the JVM; see the GraalPy reference for runtime details.

Architecture at a glance

Public imports

Most scripts can simply use from pysoup import *. The package currently re-exports the main event, world, entity, item, inventory, geometry, and scheduler APIs.

from pysoup import (
    Event, EventInfos, on_event,
    Position, BlockPosition, Direction, World,
    WorldInstance, EntityInstance,
    BlockMaterial, EntityMaterial, ItemMaterial,
    ItemStack, ItemMeta, Enchantment,
    get_max_stack_size, stackable_to,
    task, async_task, run_later, repeating, Task,
    log, broadcast, get_server,
)

Reference pages

Use Events for event payloads, Items & Inventory for the item/inventory API, and Scheduler for task execution. Reading errors covers failure modes and debugging, while Known limitations records important implementation boundaries.
