PySoup

Write small python script that execute inside your Minecraft server! PySoup provide a large and complete python lib to work with.

Why is PySoup?

PySoup is heavily inspired from PyFish, a mod that does the same thing as PySoup but for modded instead of Paper. I recommend to check out the mod. too!

My goal with PySoup was mainly to create the best python lib for it as possible. This is why you will normally never be forced to use direct java method inside of your scripts - everything is handle by the lib.

How is PySoup?

PySoup (like PyFish) is mainly using GraalPy to run the scripts: that means that you dont even need to install python to be able to run the scripts. Wonderfull, right?

Brief installation guide

First, download the plugin (on modrinth or on a github release), place it in your plugins/ folder inside of your server.

The current supported version is Paper 1.21.11
If you do not have a server that runs Paper, check out this doc to easily create one.

Then, launch your server so the plugin can create all the folder it needs.
